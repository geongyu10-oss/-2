# ⚽ 축구 선수 기록 분석 프로그램

Python과 Streamlit으로 만든 축구 선수 기록 분석 웹 앱입니다. 선수 기록을 직접 입력하면 통계를 계산하고 표와 그래프로 비교합니다.

## 기능
- 선수 기록 직접 입력
- 입력값 검사 및 같은 선수/시즌 중복 방지
- 골, 도움, 공격 포인트, 경기당 득점 계산
- 슈팅 유효율 및 패스 성공률 계산
- 선수별 순위 및 막대그래프
- 기록 CSV 다운로드 및 불러오기
- 기록 삭제 기능

## GitHub에 업로드할 파일
저장소 최상위 폴더에 아래 파일을 올립니다.
- `app.py`
- `requirements.txt`
- `README.md`

## Streamlit Community Cloud 배포
1. GitHub에서 새 저장소를 만듭니다.
2. 위 세 파일을 저장소 최상위 폴더에 업로드합니다.
3. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속해 GitHub 계정으로 로그인합니다.
4. `Create app`을 선택하고 저장소, 브랜치(`main`), 메인 파일 경로(`app.py`)를 지정합니다.
5. `Deploy`를 누릅니다.

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 데이터 관련 주의
- 실제 선수 기록은 자동으로 가져오지 않습니다. 신뢰할 수 있는 출처에서 확인한 수치를 직접 입력하세요.
- 비교할 때는 가능한 한 동일한 시즌 또는 대회 기준을 사용하세요.
- 앱의 세션 기록은 브라우저 세션이 초기화되면 사라질 수 있습니다. 기록을 보관하려면 CSV 파일로 다운로드하세요.
- 수행평가 제출 전 직접 코드를 읽고 기능을 테스트하세요. AI를 활용했다면 학교에서 요구한 활용 기록을 작성하세요.
